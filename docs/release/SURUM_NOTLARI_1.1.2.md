# AUTO YARD 1.1.2 (sürüm kodu 13) — Play Console "Yenilikler" notları (2026-10-26)

Üretimin ilk güncellemesi (üretim 1.1.1 / kod 12 ile açıldı). 1.1.1'den bu yana oyuncunun göreceği yenilikler: haftalık
drag lider tablosu (DÜNYA / ÜLKEM / ARKADAŞLAR, İZLE, profilde dereceler), koleksiyon ödülleri, etkinlik takvimi + etkinlik
aracı, GARAJI DÜZENLE › DEPO modu, 90 Hz ekranlarda 60 Hz (takılma), trafik kilidini polis açar, REKLAM YÜKLENİYOR,
hesapla girişten sonra oyun doğrudan başlar.
İç işler (notlara girmez): test döneminden kalan cihaz kaydı ilk açılışta bir kez silinir (LaunchReset; sunucudaki test
hesapları aynı gün silinir), google-services.json'a hata ayıklama anahtarının SHA-1'i eklendi.

Play Console sınırı dil başına 500 karakter (Python `len`, satır sonları dahil). Ekran adları oyundaki çevirilerle aynı
(locale/*.json). Fransızcada noktalama öncesi U+00A0.
